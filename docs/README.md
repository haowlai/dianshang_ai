## 🎯 业务与技术核心对齐点

### 1. 一期与二期边界
- **一期工程（核心产能突围）**：
  - **7-Agent 自动化生产**：素材制作从 5-10 天压缩至分钟级；
  - **AI 动态多卖点文案**：根据 Amazon/TikTok 平台特征自动定制网感文案；
  - **AI 自动合规质检**：基于 RAG 检索广告法禁词与平台规范，违规硬阻断；
  - **RAG 企业私有知识库**：集中沉淀品牌规范、爆款话术与类目知识；
  - **Agent 可观测工作台**：DAG 状态流转可视化、Token/耗时实时监控；
  - **素材审核与打包下载**：一期终点为审核通过后打包下载手动刊登。
- **二期工程（生态闭环）**：
  - 各大跨境电商平台（Amazon, TikTok, Shopify, Temu）API 对接；
  - 授权凭证管理与多平台一键刊登。

### 2. 7-Agent 状态图核心流转
```
START → Orchestrator → RequirementAnalyzer(RAG) → CreativePlanner 
      → VisualDesigner(RAG) → [条件分支: media_type]
      → ImageGenerator / VideoGenerator 
      → QualityReviewer(RAG) → [条件分支: passed?]
      ├─ passed: END
      ├─ retry (<=2次): CreativePlanner (带审核意见重试)
      └─ fail: END (人工介入)
```

### 3. 数据隔离与持久化规范
- **多租户隔离**：所有业务表必须带有 `tenant_id varchar(32)`，所有查询与向量计算强制带租户条件。
- **主键规范**：`varchar(32)`，UUID 无连字符格式。
- **向量存储**：PostgreSQL `pgvector` 扩展，1024 维（text-embedding-v4），HNSW 余弦距离索引。
- **状态存储**：开发环境 `MemorySaver`，生产环境 `PostgresSaver`。
