## 引言

### 1\.1 项目背景

环球出海科技有限公司是一家专注于北美和欧洲市场的跨境电商头部卖家，年 GMV 突破 3 亿美元，在 Amazon、TikTok Shop、Shopify、Temu 等多个平台铺货，旗下拥有超过 100 名运营人员。随着海外电商竞争白热化与短视频带货崛起，原有“人工堆叠”模式已无法支撑每日上千款 SKU 的上新需求，存在五大核心痛点：

1. 素材制作周期长达 5–10 天、依赖外包；

2. 文案撰写低效且同质化；

3. 合规审查纯人工、极易封店，曾因违禁词导致 300 万美金被冻结；

4. 品牌规范与类目知识分散、离职即断层；

5. 多平台上架繁琐。

为此，飞流智能科技基于大语言模型与多智能体技术，为环球出海打造一站式智能内容生成中台 AgenticCommerce。平台通过多智能体协作工作流与 RAG 知识库，将商品素材生成从 5–10 天压缩至分钟级，并内置合规硬阻断，实现“输入一个参数、AI 吐出全套合规素材”的闭环。

一期工程聚焦生成引擎、RAG 合规库、Agent 可观测工作台的产能突破；多平台一键刊登因涉及各平台复杂 API 对接，已确认延期至二期。

### 1\.2 文档目的

本文档用于明确 AgenticCommerce 一期、二期的功能需求、非功能需求、外部接口需求、数据需求、约束与假设、验收标准，作为产品、研发、测试、验收的共同依据。

- P1（Should Have）：重要但可后续迭代。

## 总体描述

### 2\.1 产品定位

AgenticCommerce 是面向跨境电商卖家的智能内容生成中台。一期核心能力包括：

- 多租户 SaaS 化用户与权限；

- LLM、图片、视频模型厂商可配置、可切换；

- RAG 企业知识库：品牌视觉、上架文档、合规规则、类目知识；

- SKU 与商品管理、批量任务提交；

- 7\-Agent 协作工作流：编排调度、需求分析、创意策划、视觉设计、图片生成、视频生成、质量审核；

- Agent 可观测工作台：实时 DAG、提示词、输入输出、耗时、Token、费用；

- 素材审核、在线编辑、单素材重生成、打包下载；

- 一期终点：生成 → 审核 → 手动下载上架；

- 二期：多平台一键刊登。

### 2\.2 用户角色

### 2\.3 业务目标

1. 将商品素材生成周期从 5–10 天压缩至分钟级。

2. 降低外包依赖与人工成本，支撑每日上千款 SKU 上新。

3. 通过 RAG 合规库实现违禁词与图片规范硬阻断，降低封店风险。

4. 沉淀品牌规范、类目知识、成功案例，避免人员离职导致知识断层。

5. 通过 Agent 可观测工作台提升生成过程透明度与排障效率。

6. 为二期多平台一键刊登建立素材与文案标准化基础。

### 2\.4 业务范围

一期范围：

- 用户认证与租户隔离；

- 模型厂商管理；

- RAG 知识库管理；

- SKU 与商品管理；

- 生成任务编排与批量提交；

- 7\-Agent 视觉生成工作流；

- 质量审核与合规检查；

- 素材审核、在线编辑、打包下载；

- 任务实时追踪与 Agent 可观测；

- 资产与历史记录管理。

二期范围：

- 多平台一键刊登；

- 平台授权与店铺凭证管理；

- 刊登状态回传与 SKU ↔ 平台商品映射。

### 2\.5 运行环境

系统为 Web 应用，用户通过浏览器访问。前端支持 Chrome、Edge 最新两个版本。后端提供 API 与 WebSocket 服务。系统采用容器化部署，支持本地开发与生产部署。

### 2\.6 假设与依赖

- 客户已具备各模型厂商的 API Key 与开通权限。

- 客户按行动项提供首批「广告法违禁词表」「品牌主视觉规范」用于 RAG 初始化。

- 第三方模型 API 可用性 \> 99%。

- 生成类任务采用异步处理，避免同步阻塞。

- 一期不直接对接平台发布 API，采用“生成 → 审核 → 手动下载上架”。

- 多平台一键刊登在一期产能验证通过后立项。

- RAG 检索默认 Top\-K=5，相似度阈值=0\.5，可配置。

- 质量审核最大重试次数默认 2，可配置。

## 功能需求

### F01 用户认证与租户隔离

优先级：P0

描述：提供基于多租户的用户认证与数据隔离机制。每个租户拥有独立的商品、任务、知识库、模型厂商、适配器、资产与会话数据，租户间数据严格隔离。租户内支持四类角色：租户管理员、运营、设计·内容、只读审计。

前置条件：系统管理员已创建租户；用户账号已由租户管理员创建。

基本流程：

1. 用户输入邮箱与密码登录，系统签发 JWT 访问令牌。

2. 用户进入系统后，系统根据其角色加载对应菜单与操作权限。

3. 用户的所有数据请求，系统自动按租户过滤，确保只能访问本租户数据。

4. 租户管理员可为租户内创建、停用子账号，并分配角色。

异常处理：

- 登录凭证错误，系统提示“用户名或密码错误”，连续失败 5 次锁定账号 30 分钟。

- 用户尝试跨租户访问数据，系统返回 403，并记录安全日志。

- JWT 过期，前端跳转登录页，后端返回 401。

验收标准：跨租户无法读取对方数据；四类角色权限隔离生效；登录失败锁定策略生效；生产环境 JWT 必须启用。

### F02 模型厂商管理

优先级：P0

描述：支持对 LLM、图片、视频三类模型厂商的配置与自由切换。出厂默认：LLM 为通义千问，图片为通义万相，视频为可灵 Kling。OpenAI、商汤秒画等作为可切换厂商。可为每类任务设置默认厂商，创建任务时可临时指定厂商。

前置条件：租户管理员已获取各厂商的 API Key。

基本流程：

1. 租户管理员进入模型厂商管理，选择厂商类型，填写名称、服务地址、API Key、模型名。

2. 系统将 API Key 服务端加密存储，列表页脱敏展示。

3. 管理员点击测试连接，系统调用厂商连通性接口返回是否有效。

4. 管理员将某厂商设为该类型任务的默认厂商，或保留“任务时指定”。

异常处理：

- API Key 无效，测试连接返回失败，并给出错误原因。

- 任务执行时默认厂商不可用，系统将该任务标记失败，并提示切换厂商后重试。

- 厂商配额或并发超限，任务自动排队降速，提示预计等待时间。

验收标准：支持三类厂商的增删改查与连通性测试；API Key 不落明文、列表脱敏；默认厂商与临时指定厂商均生效。

---

### F03 RAG 知识库管理

优先级：P0

描述：提供企业专属知识库，作为独立节点供各智能体检索。文档上传后自动向量化，并按四类分类管理：

1. 品牌视觉设计文档；

2. 品牌上架文档；

3. 合规规则；

4. 类目知识。

前置条件：租户管理员具备知识库管理权限；文档为 PDF、文本等受支持格式。

基本流程：

1. 管理员上传文档并选择分类，系统自动切分并向量化入库。

2. 系统展示向量化状态与分块数量。

3. 智能体在生成、质检时，通过检索接口按分类命中相关文档片段。

4. 管理员可对文档进行增删改查，删除后立即停止参与检索。

5. 系统支持查询扩展、相似度阈值过滤、重排序等检索增强能力。

异常处理：

- 文档格式不支持或解析失败，系统标记向量化失败，提示更换格式重传。

- 检索无命中，系统返回空结果，智能体按通用模板兜底生成，不阻断流程。

- 向量化服务不可用，系统提示失败并支持重试。

验收标准：文档上传后可见向量化状态；按分类检索命中率符合预期；删除文档后检索即时失效；支持向量相似度检索。

---

### F04 SKU 与商品管理

优先级：P0

描述：管理需要生成素材的商品 SKU。SKU 是商品的唯一标识编码，关联视觉生成任务与刊登任务，是平台间商品对应关系的桥梁。

前置条件：用户已登录且具备运营及以上角色。

基本流程：

1. 用户创建 SKU，填写唯一编码、商品名称、目标平台等基础信息。

2. 系统校验 SKU 编码在租户内唯一。

3. 用户可批量导入多个 SKU。

4. 系统展示 SKU 列表及其关联的任务与素材。

异常处理：

- SKU 编码重复，系统提示重复并拒绝保存。

- 批量导入字段缺失，系统逐行提示错误原因，跳过错误行并生成导入报告。

验收标准：SKU 编码租户内唯一；支持单个创建与批量导入；SKU 与任务、素材可关联追溯。

---

### F05 生成任务编排与批量提交

优先级：P0

描述：批量组织生成任务并进行多智能体编排。外层批次为一次提交 N 个 SKU，建议 10–50 个；内层每个 SKU 为一个生成任务，产出该 SKU 的文案、图片、视频。用户可勾选生成内容类型，包括文案、生图、生视频、生图加生视频，并配置风格、目标平台、生成语言、模型厂商、媒体类型等参数。

前置条件：已存在 SKU；已配置模型厂商与知识库。

基本流程：

1. 用户选择一批 SKU，配置生成选项。

2. 系统创建批次并为每个 SKU 创建生成任务，进入多智能体编排队列。

3. 系统按多智能体工作流调度执行。

4. 各任务并行或并发执行，系统通过 WebSocket 按 SKU 粒度实时推送进度。

异常处理：

- 某 SKU 生成失败，系统标记该任务失败，不影响其他 SKU，支持单任务重试。

- 厂商配额或并发超限，系统自动排队降速，并提示预计等待时间。

- 任务参数缺失，系统返回参数错误，提示必填字段。

验收标准：支持 10–50 SKU 批量提交；单批任务并发执行；单任务失败不阻塞整批；进度实时推送；任务可通过 API 创建。

### F06 多智能体工作流编排

优先级：P0

描述：系统应支持基于 LangGraph 的多智能体协作工作流。工作流包含 7 个专业 Agent：编排调度、需求分析、创意策划、视觉设计、图片生成、视频生成、质量审核。系统应支持条件路由：根据媒体类型选择图片、视频或混合分支；根据质量审核结果选择通过、重试或失败分支。系统应支持 Stream 模式，将各节点执行过程实时推送。

前置条件：已创建生成任务；已配置模型厂商与知识库。

基本流程：

1. 工作流从编排调度 Agent 开始。

2. 依次执行需求分析、创意策划、视觉设计。

3. 视觉设计后按媒体类型路由到图片生成或视频生成。

4. 生成结果进入质量审核。

5. 质量审核通过则结束；未通过且未超过最大重试次数则回到创意策划重做；超过重试次数则终止并提示人工介入。

6. 每个节点开始、结束、失败时推送可观测事件。

异常处理：

- 无图片或视频生成提示词，节点返回错误，任务标记失败。

- 节点执行异常，系统推送错误事件，前端展示失败节点与原因。

- 超过最大重试次数，系统终止任务并高亮提示人工介入。

验收标准：工作流可正确流转；7 个 Agent 节点均可观测；条件路由正确；单任务失败不影响其他任务；支持 Stream 模式与实时推送。

### F07 编排调度 Agent

优先级：P0

描述：工作流入口与协调中心。接收任务请求，解析商品信息与生成配置，制定执行计划，确定任务类型、优先级、步骤、风格方向、平台要求。

前置条件：任务已创建；商品信息与生成配置已传入。

基本流程：

1. 读取商品信息与生成配置。

2. 分析商品类型、卖点、目标平台、生成类型。

3. 输出结构化执行计划，包括任务类型、优先级、预计步骤、风格方向、平台要求。

4. 进入需求分析节点。

异常处理：

- 模型调用失败，记录错误，任务失败，支持重试。

- 返回内容无法解析，系统尝试修复，失败则使用默认计划。

验收标准：能输出结构化执行计划；工作流能进入下一节点；可观测工作台可查看该节点提示词与输出。

---

### F08 需求分析 Agent

优先级：P0

描述：深度分析商品特征，提取卖点、识别目标人群、调研竞品，生成结构化需求分析报告。过程中通过 RAG 查询企业知识库，获取品牌调性规范和合规要求。

前置条件：编排调度已完成；知识库已配置。

基本流程：

1. 读取商品信息与执行计划。

2. 检索知识库中的品牌规范、合规建议、类目知识。

3. 输出卖点、目标人群、竞品分析、视觉风格建议、知识库检索洞察。

4. 进入创意策划节点。

异常处理：

- 知识库无命中，按通用分析模板兜底，标注“无知识库增强”。

- 模型返回截断，系统自动截断并重试一次。

验收标准：产出结构化需求分析报告；RAG 命中时包含品牌规范或合规建议；下游 Agent 可解析。

---

### F09 创意策划 Agent

优先级：P0

描述：基于需求分析报告，制定创意策略，规划文案方向和视觉主题。

前置条件：需求分析报告已产出。

基本流程：

1. 读取需求分析报告。

2. 输出文案策略，包括核心标题方向、卖点展开方式、行动号召设计。

3. 输出视觉主题，包括风格定位、配色方案、构图建议。

4. 输出差异化策略，包括与竞品差异点、独特卖点强调方式。

5. 进入视觉设计节点。

异常处理：

- 模型返回超长，系统截断并重试。

- 缺少关键字段，系统使用默认策略补齐。

验收标准：产出结构化创意方案；平台定制化风格可感知；审核未通过时可回到本节点重做。

---

### F10 视觉设计 Agent

优先级：P0

描述：将创意方案转化为具体生成提示词，为图片、视频生成 Agent 提供精确生成指令。

前置条件：创意方案已产出。

基本流程：

1. 读取创意方案与知识库品牌视觉设计文档。

2. 生成主图提示词，包括正面提示词、负面提示词、构图、光线、风格、分辨率、比例。

3. 生成场景图提示词。

4. 生成卖点图提示词。

5. 如需要，生成视频分镜脚本。

6. 进入图片生成或视频生成节点。

异常处理：

- 品牌视觉文档缺失，使用通用视觉规范兜底，并标注。

- 提示词为空，任务失败，提示检查创意方案。

验收标准：输出可被图片或视频模型执行的提示词；包含负向提示词；符合品牌视觉文档要素；支持条件路由到图片生成或视频生成。

---

### F11 图片生成 Agent

优先级：P0

描述：调用外部图片生成 API，生成商品主图、场景图、卖点图。支持多模型厂商、异步调用与 Mock 降级。

前置条件：已生成图片提示词；已配置图片模型厂商。

基本流程：

1. 读取图片提示词。

2. 选择图片模型厂商。

3. 对每个提示词并发调用图片生成。

4. 收集结果，单张失败不阻断其他图片。

5. 生成结果进入质量审核。

异常处理：

- 单张图片生成失败，系统自动重试，仍失败则标记该图失败，其余图片不受影响。

- 无 API Key 或调用失败且允许 Mock，系统返回占位图并标记为 Mock 资产。

- 出图触发图片规范红线，交由质量审核阻断并打回。

验收标准：按配置产出主图、场景图、卖点图；出图符合品牌视觉文档要素；单图失败不影响其他图；Mock 降级可用。

### F12 视频生成 Agent

优先级：P0

描述：调用外部视频生成 API，生成商品展示短视频，并输出分镜脚本。默认时长 15–30 秒，适配 TikTok 竖屏。

前置条件：已生成视频提示词或分镜脚本；已配置视频模型厂商。

基本流程：

1. 读取视频提示词与分镜脚本。

2. 调用视频模型生成商品展示视频。

3. 视频与分镜脚本入库为素材资产。

4. 生成结果进入质量审核。

异常处理：

- 视频生成超时，按默认时长 3 倍设超时上限，超时标记失败并支持重试。

- 分镜脚本成功但视频渲染失败，保留分镜脚本，仅视频标记失败，可单独重试视频。

- 无视频 API Key，可 Mock 降级或标记失败。

验收标准：产出商品展示视频与分镜脚本；时长与画幅符合配置；分镜脚本与视频内容一致；失败可单独重试。

### F13 质量审核与合规检查 Agent

优先级：P0

描述：对生成结果做多维度审核。审核维度包括技术质量、内容相关性、视觉美感、合规检查。合规检查包含广告法禁词、平台审核要点、品牌规范符合度。命中红线则打回上游重做；低分仅预警不阻断。产出合规报告。

前置条件：生成结果已产出；知识库已录入合规规则。

基本流程：

1. 检索合规规则，对文案与图片提示词进行红线扫描。

2. 计算总分与各维度得分。

3. 输出审核报告，包括总分、各维度得分、是否通过、建议。

4. 审核通过则结束；未通过且未超过最大重试次数则回到创意策划重做；超过重试次数则终止并提示人工介入。

异常处理：

- 命中红线且重做 N 次仍不合格，系统终止该任务并高亮提示人工介入。

- 合规规则库为空，系统提示“未配置合规规则”，默认放行但显著警告。

- 审核报告为空，路由为失败。

验收标准：命中禁词或图片规范红线的结果被阻断；质量低分产生预警；合规报告可查看；重试次数默认 2，可配置。

### F14 素材审核、在线编辑与打包下载

优先级：P0

描述：生成结果进入待审核状态，运营可在线编辑文案、对单张图或单个视频单独重新生成，满意后打包下载。一期流程终点为“下载后手动上架”。

前置条件：生成任务已完成并通过质量评估。

基本流程：

1. 运营查看待审核结果，包括文案、图片、视频、合规报告。

2. 运营在线编辑文案。

3. 运营对不满意的单张图或单个视频点击重新生成。

4. 运营确认满意后，选择打包下载，系统按 SKU 打包文案文件、图片、视频、分镜脚本。

5. 系统记录下载操作日志。

异常处理：

- 重新生成仍不满意，用户可多次重新生成，或切换风格、厂商后重试。

- 打包文件过大，系统分卷或异步生成下载链接，完成后通知用户。

验收标准：支持文案在线编辑；单图或单视频独立重新生成；打包下载内容完整、可追溯；操作日志保留不少于 30 天。

### F15 任务实时追踪与 Agent 可观测

优先级：P0

描述：通过 WebSocket 实时推送任务进度，Agent 执行过程可观测。工作台采用 DevOps 风格，展示 DAG 流程图、节点状态、提示词、输入输出、子调用、耗时、Token、费用、上游与下游。支持查看每个智能体节点的输入、输出、耗时、状态，提升透明性与排障效率。

前置条件：存在进行中的生成任务。

基本流程：

1. 客户端订阅任务或批次进度通道。

2. 系统在每个 Agent 节点开始、结束、失败时推送事件，包含 SKU 粒度、节点名、状态、耗时、Token、费用、输入输出摘要。

3. 用户可查看单个任务的 Agent 执行链路与节点详情。

4. 前端工作台展示 DAG 流程图，节点状态包括等待、运行中、成功、失败。

5. 点击节点查看概览、提示词、输入输出、子调用。

6. System 与 Human Prompt 支持完整展示与复制。

异常处理：

- WebSocket 断线，系统自动重连，重连后补发未消费的进度事件。

- 节点执行异常，系统推送错误事件，前端展示失败节点与原因。

- 连接数过多，服务端限制单任务订阅数，超限返回错误。

验收标准：进度实时推送延迟小于 1 秒；可查看各 Agent 节点执行链路；断线重连后不丢进度；点击节点能查看完整 System 与 Human Prompt 和输入输出数据；前端 15 个页面路由正常工作。

### F16 资产与历史记录管理

优先级：P1

描述：对已生成的素材资产与历史任务统一管理，支持按 SKU、批次、时间、状态检索、预览与复用，沉淀企业数字资产。

前置条件：存在历史生成结果。

基本流程：

1. 用户按条件检索历史任务与素材资产。

2. 用户预览素材，或复制历史配置作为新任务模板。

3. 系统保留操作与下载日志，保留时间不少于 30 天。

异常处理：

- 素材文件过期或丢失，系统标记失效并提示重新生成。

- 对象存储不可用，系统返回服务不可用，提示稍后重试。

验收标准：可按多维度检索历史；素材可预览、可复用为模板；日志可审计。

### F17 多平台一键刊登（二期）

优先级：P2，二期工程

描述：将审核通过的素材与文案一键推送到 Amazon、TikTok Shop、Shopify、Temu 等多个平台，形成“生成 → 审核 → 刊登”完整闭环。涉及平台 API 对接与店铺授权认证。

前置条件：一期产能验证通过后立项；已配置各平台店铺凭证。

基本流程：

1. 用户选择已审核通过的商品与目标平台。

2. 系统调用各平台 API 提交 Listing，并返回刊登状态，包括成功、失败、需修正。

3. 系统回传刊登结果与外部商品 ID，建立 SKU 与平台商品映射。

异常处理：

- 平台 API 变更或限流，系统按平台规则重试与降速，并提示用户手动兜底。

- 刊登被平台拒绝，系统回传拒绝原因，引导用户修正后重投。

验收标准：支持多平台授权与一键刊登；刊登状态可回传、可追溯。

## 非功能需求

### 4\.1 性能需求

- 页面加载时间：P95 小于 2 秒。

- API 响应时间：P95 小于 1 秒，生成类任务为异步，不计入此响应时限。

- 并发能力：初期支持 20–50 并发生成任务；单批次 10–50 个 SKU；日处理不少于 200 SKU。

- WebSocket 进度推送延迟小于 1 秒。

- RAG 检索：Top\-K 默认 5，相似度阈值默认 0\.5，支持查询扩展与重排序。

### 4\.2 安全需求

- 所有 API 需要认证，按租户与角色授权；本地开发可关闭认证。

- 敏感数据加密存储，厂商 API Key 服务端加密，列表脱敏展示。

- 操作日志保留 30 天。

- 租户间数据严格隔离，请求级按租户过滤，数据库级隔离。

- 文件上传校验类型与大小，防路径穿越。

- WebSocket 需要鉴权，禁止跨租户订阅。

### 4\.3 可用性需求

- 系统可用性大于 99\.5%。

- 支持 Chrome、Edge、Safari 最新两个版本。

- 外部模型厂商失败时，可在开发或演示环境 Mock 降级。

- 关键任务支持重试与断点恢复。

### 4\.4 可维护性需求

- 代码需有基本注释，关键业务逻辑、接口、复杂算法必须注释。

- 需提供部署文档和运维手册。

- 模型厂商通过配置切换，新增厂商不改动业务逻辑。

- 业务逻辑分层清晰，接口粒度细化拆分，完整注释，可先 Mock 实现。

- 数据库表与字段必须有注释，常用查询字段建索引。

### 4\.5 可观测性需求

- 每个 Agent 节点记录输入、输出、提示词、耗时、Token、费用、状态、错误。

- 支持按任务、批次、SKU 追踪执行链路。

- 平台内建 Agent 可观测工作台，WebSocket 实时推送。

- 可选支持 LangSmith 追踪。

### 4\.6 兼容性与合规

- 生成内容需经过合规红线检查。

- 图片与视频需符合目标平台规范。

- 广告法禁词、平台规则、品牌规范可配置。

- 数据保留与删除需符合客户合规要求。
