## 一、学习开发端硬件配置推荐（个人 PC / 笔记本）

在开发 AgenticCommerce 项目时，如果你主要**调用云端大模型 API（如阿里百炼 DashScope）**，本地机器只需承载 Docker 容器（PostgreSQL、Redis、MinIO）以及 FastAPI 和前端 Vite 开发服务，因此对显卡（GPU）没有硬性要求。

### 1.1 开发者机器推荐配置清单（Windows / macOS）

| 硬件维度 | 最低能跑配置 (学习演示) | 舒适开发配置 (推荐主力机) | 极客级配置 (本地跑私有模型) |
| :--- | :--- | :--- | :--- |
| **CPU** | 4 核 (Intel i5-10代 / AMD R5-3600) | 8 核 16 线程 (Intel i7-13700 / AMD R7-7700) | 16 核 32 线程 (Intel i9 / AMD R9) |
| **系统内存 (RAM)** | **16 GB** (低于16G开Docker会卡顿) | **32 GB DDR4/DDR5** | **64 GB DDR5** |
| **硬盘 (SSD)** | 512 GB SATA/NVMe SSD | **1 TB NVMe M.2 高速 SSD** | 2 TB PCIe 4.0 NVMe SSD |
| **独立显卡 (GPU)** | 集成显卡（核显）即可 | NVIDIA RTX 3060 12G（可选） | **NVIDIA RTX 4090 24G 或 双卡 3090** |
| **操作系统** | Windows 10/11 64位 (开启 WSL2) | Windows 11 专业版 或 macOS (M2/M3) | Ubuntu 22.04 LTS 或 macOS M3 Max |

> **⚠️ 特别提醒（内存是第一瓶颈）**：开发时浏览器常开数十个标签，后台挂着 4 个 Docker 容器，前端 Vite 实时编译，后端热重载，**16GB 内存通常占用率会在 85%~90%**，强烈建议升级到 **32GB 内存**！

---

### 1.2 本地运行 Docker 中间件对内存/CPU 的真实消耗

项目运行时的底座资源消耗实测数据：

| 运行组件 | 稳定闲置内存 | 压测高并发内存 | CPU 占用 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **PostgreSQL 16 + pgvector** | ~120 MB | ~500 MB | < 5% | 1024 维向量构建索引时会有短暂 CPU 突发 |
| **Redis 7** | ~15 MB | ~80 MB | < 1% | 极轻量，占用几乎可忽略 |
| **MinIO 对象存储** | ~150 MB | ~400 MB | 1% ~ 3% | 高频上传图片/视频时有瞬时 I/O |
| **FastAPI 后端服务** | ~90 MB | ~250 MB | 2% ~ 5% | 异步 I/O 驱动，极其节省内存 |
| **Vue 3 Vite 开发服务器** | ~180 MB | ~350 MB | < 2% | Node.js 进程 |
| **合计** | **约 550 MB** | **约 1.6 GB** | **轻量** | 本机开发完全无压力！ |

## 二、生产环境云服务器选型（阿里云 ECS 方案）

### 2.1 云服务器选型阶梯表（学习演示 vs 商业生产）

针对不同业务阶段，推荐阿里云 ECS 规格如下：

| 阶段 / 场景 | 推荐 ECS 实例规格 | CPU / 内存 | 系统盘 / 数据盘 | 预估月度成本 (参考) | 承载能力 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **个人自学 / 结课毕设** | 轻量应用服务器 | 2 核 2G 或 2 核 4G | 60 GB 高效云盘 | 约 35 ~ 60 元/月 | 单人测试、小规模演示 |
| **团队测试 / 预发环境** | ECS 算力型 `e` 系列 | 2 核 8G 或 4 核 8G | 100 GB ESSD AutoPL | 约 120 ~ 220 元/月 | 10 人并发联调 |
| **商业生产标准版** | ECS 通用型 `g7` / `g8i` | **4 核 16G** | 200 GB ESSD PL1 | 约 450 ~ 680 元/月 | 日均生成 5,000+ SKU 内容 |
| **企业高可用集群** | 2 台 ECS 计算型 `c7` (4核8G) + RDS PG + 云 Redis + OSS | 分离式云产品架构 | 按需挂载 | 约 1,800 元/月 | 支撑日活 10 万+ 跨境电商团队 |

---

### 2.2 存储盘类型与带宽计费模式避坑建议

1. **磁盘类型**：坚决不要买便宜的「普通云盘」，必须选择 **ESSD 云盘（系统盘建议 80GB，数据盘建议 100GB+）**。pgvector 在做海量向量距离相似度计算时，极其依赖磁盘随机读取 IOPS。
2. **带宽选择（巨大省钱技巧）**：
   - 如果选择「固定 5Mbps 带宽」，一个月费用高达上百元，而且生成高清图片时加载极其缓慢；
   - **强烈推荐选择「按使用流量计费」**：峰值带宽直接拉满到 **100 Mbps**！1GB 流量仅约 0.8 元人民币，平时展示工作台加载素材快如闪电，无访问时不花一分钱。

## 三、本地私有化大模型显存 (VRAM) 严密精算模型

很多企业出于数据安全或海外合规考虑，希望在局域网内用自己的显卡运行开源大模型（如通义千问 Qwen2.5 系列、Llama 3 等），拒绝向第三方 API 传输商业机密。**那么到底需要多少显存的显卡？**

### 3.1 大语言模型 (LLM) 推理显存计算公式

模型权重所占用的物理显存，与模型的参数量（Parameters）和精度位数（Bit）严格成正比：

$$\text{权重显存 (GB)} \approx \text{参数量 (Billion)} \times \frac{\text{量化位数 (bit)}}{8}$$

实际运行时，除了模型权重，还需要预留 **KV Cache（上下文长度缓存）** 和 **CUDA 推理上下文缓冲区（约占 1.2 倍冗余）**：

$$\text{总显存需求} \approx (\text{权重显存} + \text{KV Cache 显存}) \times 1.2$$

- **FP16 / BF16 (16位半精度)**：每个参数占用 2 字节（Byte）；
- **INT8 (8位量化)**：每个参数占用 1 字节；
- **INT4 / AWQ / GPTQ (4位量化)**：每个参数仅占用 0.5 字节（精度损失仅约 1~2%，但显存砍掉 75%！）。

---

### 3.2 常见开源大模型显存需求对照表 (Qwen2.5 系列)

以阿里官方开源的 **Qwen2.5** 系列模型为例，在本地部署推理时的显存需求如下：

| 开源模型名称 | FP16 原始显存 | INT8 量化显存 | INT4 量化显存 (推荐) | 推荐配备显卡硬件 |
| :--- | :--- | :--- | :--- | :--- |
| **Qwen2.5-1.5B** | ~3.5 GB | ~2.0 GB | **~1.2 GB** | 任何老显卡 / 甚至轻薄本 CPU 均可运行 |
| **Qwen2.5-7B** (电商主力) | ~16.5 GB | ~9.5 GB | **~5.8 GB** | **RTX 3060 12G / RTX 4060Ti 16G**（甜品级） |
| **Qwen2.5-14B** (高智商版) | ~32.0 GB | ~18.0 GB | **~10.5 GB** | **RTX 3090 24G / RTX 4090 24G**（消费级旗舰） |
| **Qwen2.5-32B** (极强逻辑) | ~72.0 GB | ~40.0 GB | **~24.0 GB** | **单卡 RTX 4090 24G** (4-bit 极限跑) 或 双卡 3090 |
| **Qwen2.5-72B** (满血超大) | ~160.0 GB | ~88.0 GB | **~48.0 GB** | **双卡 A100/A800 80G** 或 4卡 RTX 4090 24G |

## 四、商业 API vs 本地私有化算力成本拐点测算

### 4.1 阿里云百炼 API 计费清单与单 SKU 生成成本模型

如果采用本项目默认架构（调用云端商业 API），其计费规则与单次生成成本如下：

1. **文本生成 (Qwen-Max / Qwen-Plus)**：
   - 输入：0.004 元 / 1,000 tokens
   - 输出：0.012 元 / 1,000 tokens
   - 7-Agent 完整走完一轮文案策划消耗约 3,000 tokens，**文本成本约 0.03 元**。
2. **图片生成 (通义万相 Wanx 2.1)**：
   - 1024×1024 商业标准图片：**约 0.16 元 / 张**
   - 单 SKU 生成 3 张（白底图、场景图、细节特写）：**生图成本约 0.48 元**。
3. **视频生成 (通义万相 / 可灵 Kling 5秒短视频)**：
   - 5秒 720P/1080P 电商展示视频：**约 0.80 ~ 1.50 元 / 条**。

$$\text{单 SKU 完整物料生成总成本} \approx 0.03\text{ (文案)} + 0.48\text{ (3张图)} + 1.20\text{ (短视频)} \approx \mathbf{1.71 \text{ 元人民币}}$$

### 4.2 决策矩阵：什么时候买卡自建？什么时候调云端 API？

| 考量维度 | 方案 A：云端商业 API (阿里云百炼 DashScope) | 方案 B：本地买卡私有化 (RTX 4090 / A100) |
| :--- | :--- | :--- |
| **初期硬件投入** | **0 元** (按量付费，充值 100 元即可启动) | **约 1.8 万 ~ 5 万元** (购买 4090 主机或二手服务器) |
| **运维复杂度** | **极低** (无需管驱动、CUDA、显存溢出 OOM、散热) | **极高** (需维护 Linux、NVIDIA Driver、vLLM、Ollama) |
| **并发弹性扩展** | **无限弹性** (瞬间并发 100 个任务无压力) | **受限** (单卡同时最多跑 2~3 个任务，排队耗时长) |
| **数据保密性** | 数据传输至阿里云，适合通用商品公开数据 | 数据完全不出局域网，适合军工、保密新品研发 |
| **成本临界平衡点** | **日生成量 < 1,000 个 SKU 时，调 API 绝对划算** | **日生成量持续 > 3,000 个 SKU，且稳定运行 1 年以上时自建更省钱** |

**结论建议**：  
对于 99% 的个人开发者、高校课题研究和初创电商团队，**坚决优先使用云端 API 方案**！省去高昂硬件采购与驱动运维烦恼，把全部精力集中在业务流程、提示词调优与多智能体协同上！
