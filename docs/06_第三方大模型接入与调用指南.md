## 1. 阿里云百炼 · 通义千问

通义千问是本平台出厂默认的 **LLM（用于需求分析、创意文案、视觉设计、合规审查）** 与 **Embedding（用于 pgvector 知识库向量检索）** 底层模型。

### 1.1 平台入口与文档
- **百炼控制台**：[https://bailian.console.aliyun.com/](https://bailian.console.aliyun.com/)
- **API Key 申请**：控制台右上角 -> API-KEY -> 创建新的 API-KEY
- **开发文档中心**：[https://help.aliyun.com/zh/model-studio/developer-reference/](https://help.aliyun.com/zh/model-studio/developer-reference/)

### 1.2 文本与结构化生成 (Qwen-Plus / Qwen-Max)
- **API 端点**：`https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`
- **请求方法**：`POST`
- **请求头**：
  ```http
  Authorization: Bearer <DASHSCOPE_API_KEY>
  Content-Type: application/json
  ```
- **请求示例 (Python httpx)**：
  ```python
  import httpx

  headers = {
      "Authorization": f"Bearer {DASHSCOPE_API_KEY}",
      "Content-Type": "application/json"
  }
  payload = {
      "model": "qwen-plus",
      "messages": [
          {"role": "system", "content": "You are a cross-border e-commerce creative expert."},
          {"role": "user", "content": "Generate 5 high-converting bullet points for wireless earbuds."}
      ],
      "response_format": {"type": "json_object"},
      "temperature": 0.7
  }
  response = httpx.post("https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions", headers=headers, json=payload)
  print(response.json())
  ```

### 1.3 向量化嵌入 (text-embedding-v4)
- **API 端点**：`https://dashscope.aliyuncs.com/api/v1/services/embeddings/text-embedding/text-embedding`
- **维度**：`1024`（与本平台 PostgreSQL pgvector 完全匹配）
- **请求体**：
  ```json
  {
    "model": "text-embedding-v4",
    "input": {
      "texts": ["北美亚马逊 2026 广告法合规违禁词表：禁止使用 best, cure, 100%"]
    },
    "parameters": {
      "dimension": 1024
    }
  }
  ```

## 2. 阿里云百炼 · 通义万相 (Wanx 2.1)

通义万相负责商品主图、场景/卖点图的高清批量渲染。

### 2.1 平台入口与文档
- **官方文档**：[通义万相文生图开发参考](https://help.aliyun.com/zh/model-studio/developer-reference/tongyi-wanxiang-api)
- **计费与开通**：在阿里云百炼模型广场中开通 `wanx2.1-t2i-turbo` 或 `wanx-v1`。

### 2.2 调用机制 (异步提交 + 状态轮询)
通义万相生图为异步接口：

#### 步骤 1：提交生图异步任务
- **端点**：`https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis`
- **请求头**：`X-DashScope-Async: enable`
- **请求 Payload**：
  ```json
  {
    "model": "wanx2.1-t2i-turbo",
    "input": {
      "prompt": "Commercial product photography of modern wireless headphones on a white pedestal, soft studio lighting, ultra-detailed, 8K resolution, minimalist luxury aesthetic",
      "negative_prompt": "blurry, low quality, deformed, watermark, text, artifacts"
    },
    "parameters": {
      "size": "1024*1024",
      "n": 1
    }
  }
  ```
- **响应示例**：
  ```json
  {
    "output": {
      "task_id": "778899aa-bbcc-ddee-ff00-112233445566",
      "task_status": "PENDING"
    },
    "request_id": "req-123456"
  }
  ```

#### 步骤 2：轮询任务执行结果
- **端点**：`GET https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}`
- **响应示例 (成功状态)**：
  ```json
  {
    "output": {
      "task_id": "778899aa-bbcc-ddee-ff00-112233445566",
      "task_status": "SUCCEEDED",
      "results": [
        {
          "url": "https://dashscope-result-sh.oss-cn-shanghai.aliyuncs.com/123/output.png"
        }
      ]
    }
  }
  ```
- **落地处理**：平台收到图片 URL 后自动下载并转存至本地 MinIO 桶 `agentic-assets`，生成平台唯一资产 ID。

## 3. 快手 · 可灵 AI (Kling)

可灵 AI 是本平台默认的动态电商短视频与分镜脚本渲染模型。

### 3.1 平台入口与文档
- **官方开放平台**：[https://klingai.kuaishou.com/](https://klingai.kuaishou.com/)
- **开发者文档**：[https://klingai.kuaishou.com/developer/docs](https://klingai.kuaishou.com/developer/docs)

### 3.2 鉴权方式
可灵 AI 使用由 `AccessKeyId` 与 `AccessKeySecret` 计算签发的 JWT 签名或 Bearer Token：
- **请求头**：`Authorization: Bearer <KLING_API_TOKEN>`

### 3.3 文生短视频 (Text-to-Video)
- **API 端点**：`https://api.klingai.com/v1/videos/text2video`
- **请求 Payload**：
  ```json
  {
    "model_name": "kling-v1",
    "prompt": "Smooth 360-degree rotation of sleek matte black wireless headphones, dynamic commercial lighting, cinematic depth of field, 4k",
    "negative_prompt": "distortion, flickering, dark, low resolution",
    "cfg_scale": 0.5,
    "mode": "std",
    "aspect_ratio": "9:16",
    "duration": "5"
  }
  ```
- **响应结果**：返回 `task_id`，客户端轮询 `GET https://api.klingai.com/v1/videos/text2video/{task_id}` 直至状态变为 `succeed`。

## 4. OpenAI 兼容接口

平台内置对标准 OpenAI 协议（`gpt-4o`, `gpt-4o-mini`）的支持，可作为备用评测与文本多模型比对引擎。

## 6. 在 AgenticCommerce 中配置与切换

### 6.1 配置文件对应关系
在项目根目录 `.env` 中填入申请好的 Key 即可立即切换至真实调用：

```env
# 阿里千问与万相
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WANX_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 快手可灵
KLING_API_KEY=your_kling_jwt_token_here
KLING_ACCESS_KEY_ID=your_ak_here
KLING_ACCESS_KEY_SECRET=your_sk_here

# 是否允许 Mock 占位 (有真实 Key 建议设为 false，无 Key 时设为 true 自动降级保障系统正常运行)
ALLOW_MOCK_ASSETS=true
```

### 6.2 优雅降级设计
当环境变量中未提供对应 API Key，或外部厂商网络出现临时抖动（超时/限流 429）时，平台会**自动切换为内置高保真商业 Mock 资产与真实级文案**，并在系统日志中明确记录厂商降级状态，绝不阻塞前端界面与任务流水线运行。
