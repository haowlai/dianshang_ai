## 一、准备工作：阿里云 ECS 云服务器选购与配置

### 1.1 硬件规格与操作系统推荐

登录 [阿里云控制台](https://ecs.console.aliyun.com/)：

1. **实例规格**：
   - **入门学习/演示**：轻量应用服务器 或 ECS 共享型 `s6` / 算力型 `e`（**2 核 CPU，4GB 内存**，系统盘 50GB 以上）。
   - **生产商用标准**：ECS 通用型 `g7` / 计算型 `c7`（**4 核 CPU，8GB 或 16GB 内存**）。
2. **操作系统镜像**：
   - 强烈推荐选择：**Ubuntu 22.04 64位** 或 **Alibaba Cloud Linux 3 (兼容 CentOS)**。
   - **切记**：不要选 Windows Server（宝塔 Windows 版和 Linux 版生态有差异，Linux 性能更优且更稳定）。
3. **公网带宽**：
   - 学习/测试建议选择「**按使用流量计费**」，峰值带宽拉到 100Mbps（速度飞快，不产生访问就不扣钱，1GB 流量约 0.8 元）。

---

### 1.2 安全组端口放行清单（核心避坑点）

> **⚠️ 90% 的新手第一次部署失败，都是因为没在云服务器控制台开放安全组端口！**

在阿里云 ECS 实例详情页 -> **安全组** -> **入方向规则** -> 点击「**手动添加**」，将以下端口全部放行：

| 授权策略 | 协议类型 | 端口范围 | 授权对象 | 作用说明 |
| :--- | :--- | :--- | :--- | :--- |
| 允许 | TCP | **22** | 0.0.0.0/0 | SSH 终端远程连接工具（Xshell/FinalShell） |
| 允许 | TCP | **80** | 0.0.0.0/0 | HTTP 网页常规访问 |
| 允许 | TCP | **443** | 0.0.0.0/0 | HTTPS 加密访问 |
| 允许 | TCP | **8888** | 0.0.0.0/0 | 宝塔面板默认管理入口端口 |
| 允许 | TCP | **8002** | 0.0.0.0/0 | FastAPI 后端 API 测试端口（可选） |
| 允许 | TCP | **9000** | 0.0.0.0/0 | MinIO 对象存储 API 端口 |
| 允许 | TCP | **9001** | 0.0.0.0/0 | MinIO 控制台后台管理页面端口 |

## 二、一键安装宝塔 Linux 面板（图形化运维界面）

### 2.1 SSH 登录云服务器

打开 Windows 系统的 PowerShell、CMD 或工具 FinalShell / Xshell：

```bash
ssh root@<你的阿里云公网IP>
# 输入你在购买服务器时设置的 root 密码
```

---

### 2.2 官方极速安装命令

登录成功后，在终端中直接粘贴执行以下宝塔官方 Ubuntu 安装脚本：

```bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

过程中若出现 `Do you want to install Bt-Panel to the /www directory now?(y/n):`，直接输入 `y` 按回车。

约 2 分钟后，屏幕末尾会打印出如下关键信息（**立刻截图保存！**）：

```text
==================================================================
Congratulations! Installed successfully!
==================================================================
外网面板地址: http://123.56.xx.xx:8888/a8b9c0d1
内网面板地址: http://192.168.0.1:8888/a8b9c0d1
username: bt_user_xxxx
password: bt_pass_yyyy
==================================================================
```

---

### 2.3 首次登录面板与安全初始化设置

1. 在电脑浏览器中，打开终端里给出的 **外网面板地址**（必须带最后的随机安全入口后缀，如 `/a8b9c0d1`）。
2. 输入给出的账号和密码登录。
3. 首次进入会弹出「推荐安装套件」，先**点击叉号跳过**，我们将在下一步精确安装项目所需的指定组件。

## 三、宝塔软件商店一键安装基础设施

进入宝塔面板左侧菜单 -> **软件商店**：

### 3.1 核心中间件套件安装
1. **Nginx**：在搜索框输入 `Nginx`，选择 `Nginx 1.24` 或 `1.26`，点击「**安装**」-> 选择「**极速安装**」。
2. **PostgreSQL**：在应用搜索中搜索 `PostgreSQL`，安装版本选择 **PostgreSQL 16**。
3. **Redis**：搜索 `Redis`，选择 **Redis 7.0**，点击安装。安装完毕后，在 Redis 设置中开启 `AOF 持久化`。
4. **Docker 管理器**：搜索 `Docker`，点击一键安装（用于最简便拉起 MinIO）。

---

### 3.2 向量扩展 pgvector 一键编译加载

宝塔安装的 PostgreSQL 默认不带向量扩展，我们需要在终端中执行 3 行命令完成编译：

在宝塔左侧菜单点击「**终端**」，直接在网页终端中粘贴执行：

```bash
# 1. 安装编译工具与 postgresql 源码头文件
sudo apt-get install -y git build-essential postgresql-server-dev-16

# 2. 拉取 pgvector 源码并编译
cd /tmp
git clone --branch v0.7.0 https://github.com/pgvector/pgvector.git
cd pgvector
make
sudo make install

# 3. 进入 PostgreSQL 终端开启扩展
sudo -u postgres psql -c "CREATE EXTENSION IF NOT EXISTS vector;"
```
看到 `CREATE EXTENSION` 即表示 AI 向量能力已成功植入数据库！

---

### 3.3 MinIO 对象存储安装（通过宝塔 Docker 一键拉起）

在宝塔面板的「**终端**」执行以下命令，一秒拉起 MinIO 并持久化数据：

```bash
docker run -d \
  --name agentic-minio \
  --restart always \
  -p 9000:9000 \
  -p 9001:9001 \
  -e "MINIO_ROOT_USER=minioadmin" \
  -e "MINIO_ROOT_PASSWORD=minioadmin" \
  -v /www/server/miniodata:/data \
  minio/minio server /data --console-address ":9001"
```

拉起后在浏览器访问 `http://<云服务器公网IP>:9001`：
- 用户名：`minioadmin`
- 密码：`minioadmin`
- 进入后点击 **Create Bucket**，输入桶名：`agentic-assets`，并将 Access Policy 设置为 `Public`（允许公开读取生成的图片）。

## 四、后端 Python FastAPI 服务可视化部署

### 4.1 安装「Python 项目管理器」与 Python 3.12 运行时
1. 在宝塔**软件商店**中搜索 `Python项目管理器`，点击安装。
2. 打开「Python项目管理器」-> 点击「**版本管理**」-> 安装 **Python 3.12.x**。

---

### 4.2 代码上传与虚拟环境构建
1. 打开宝塔左侧「**文件**」菜单，进入 `/www/wwwroot/` 目录。
2. 点击「**新建目录**」，命名为 `dianshang`。
3. 将本地项目文件（代码文件夹 `app`, `conf`, `prompts`, `main.py`, `pyproject.toml`）压缩为 `backend.zip`，点击「**上传**」并在此处解压。

---

### 4.3 配置 .env 生产环境变量
在 `/www/wwwroot/dianshang/` 目录下新建一个名为 `.env` 的文件，写入以下配置：

```ini
APP_NAME=AgenticCommerce
APP_ENV=prod
PORT=8002

# 数据库配置 (连接本地 PostgreSQL)
POSTGRES_HOST=127.0.0.1
POSTGRES_PORT=5432
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=agentic_commerce

# 缓存配置
REDIS_URL=redis://127.0.0.1:6379/0

# 对象存储配置 (MinIO)
MINIO_ENDPOINT=127.0.0.1:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=agentic-assets

# 大模型 API Key (必填真实阿里百炼 Key)
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DEFAULT_LLM_MODEL=qwen-max
```

---

### 4.4 数据库表结构初始化 (init_db 与 seed_data)
在宝塔终端进入该项目目录，激活虚拟环境并执行建表：

```bash
cd /www/wwwroot/dianshang

# 创建虚拟环境
python3.12 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -e .

# 执行建表与预置种子数据
python -m app.scripts.init_db
python -m app.scripts.seed_data
```
当屏幕出现 `[Success] Database tables initialized successfully!` 与种子数据灌入成功时，数据库即全部就绪！

---

### 4.5 启动服务与进程守护（Gunicorn / Uvicorn）
在宝塔「**Python项目管理器**」中：
1. 点击「**添加项目**」：
   - **项目名称**：`agentic-backend`
   - **路径**：`/www/wwwroot/dianshang`
   - **Python版本**：选择 `3.12`
   - **框架**：选择 `FastAPI` (或使用 自定义)
   - **启动方式**：`uvicorn main:app --host 0.0.0.0 --port 8002 --workers 2`
   - **端口**：`8002`
2. 点击「确定」，状态变为**绿色运行中**！

## 五、前端 Vue 3 项目托管与 Nginx 反向代理

### 5.1 前端 Dist 静态文件上传
1. 在本地电脑终端进入 `frontend` 目录：
   ```bash
   pnpm install
   pnpm build
   ```
2. 本地 `frontend/dist` 目录下会生成打包产物（`index.html`, `assets/` 静态文件夹）。
3. 将本地 `dist` 打包为 `dist.zip`。
4. 打开宝塔「**文件**」菜单，进入 `/www/wwwroot/`，新建目录 `agentic-web`，将压缩包上传并解压到此。

---

### 5.2 宝塔新建站点与目录绑定
1. 在宝塔面板左侧点击「**网站**」->「**添加站点**」：
   - **域名**：输入你的域名（如 `ai.yourdomain.com`，如果没有域名，可直接输入服务器公网 IP）。
   - **根目录**：选择刚刚解压的 `/www/wwwroot/agentic-web`。
   - **FTP / 数据库**：选择不创建。
   - 点击「提交」。

---

### 5.3 配置伪静态（解决 Vue Router 刷新 404）
在站点列表中找到刚添加的站点，点击「**设置**」->「**伪静态**」，粘贴以下内容并保存：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

---

### 5.4 完整 Nginx 反向代理配置（API、WebSocket、MinIO）
点击站点设置 ->「**配置文件**」，在其中找到最外层的 `server { ... }` 块，在其内部添加以下三个关键的反向代理块：

```nginx
    # ── 1. 后端 RESTful API 反向代理 ──
    location /api/ {
        proxy_pass http://127.0.0.1:8002/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 60s;
        proxy_read_timeout 300s; # 增加大模型生成等待超时
    }

    # ── 2. WebSocket 长连接反向代理（DAG状态实时流推） ──
    location /api/v1/ws/ {
        proxy_pass http://127.0.0.1:8002/api/v1/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }

    # ── 3. MinIO 对象存储静态资源反向代理 ──
    location /agentic-assets/ {
        proxy_pass http://127.0.0.1:9000/agentic-assets/;
        proxy_set_header Host $host;
    }
```
点击保存，Nginx 将自动重载！

## 六、域名绑定与 Let's Encrypt 免费 SSL 证书一键开启

在站点设置中：
1. 点击「**SSL**」选项卡。
2. 勾选你的域名，选择「**Let's Encrypt**」证书提供商。
3. 勾选管理员邮箱，点击「**申请并保存**」。
4. 申请成功后，打开右上角的「**强制 HTTPS**」开关！
现在你在任何地方通过 `https://ai.yourdomain.com` 即可打开带着安全绿锁的 AgenticCommerce 工作台！

## 七、小白高频踩坑与排错自查手册（502、跨域、WS 断连）

| 异常现象 | 核心排查点 | 解决方案 |
| :--- | :--- | :--- |
| **访问报 502 Bad Gateway** | 8002 端口后端服务未启动或崩溃退出 | 检查宝塔 Python 项目管理器中进程是否在线；查看 `logs/error.log` 查看是否缺少 Python 依赖包。 |
| **页面刷新显示 404 Not Found** | Nginx 未配置 SPA 路由重定向 | 检查 5.3 节的「伪静态」，确保配置了 `try_files $uri $uri/ /index.html;`。 |
| **生成的图片预览裂开或 403** | MinIO 存储桶为 Private 私有 | 登录 MinIO 控制台 (9001 端口)，进入 `agentic-assets` 桶将 Access Policy 修改为 `Public`。 |
| **DAG 进度条不动，WebSocket 断连** | Nginx 缺失 Upgrade 请求头 | 检查 5.4 节反向代理，确保配置了 `proxy_set_header Upgrade $http_upgrade;` 和 `Connection "upgrade";`。 |
| **保存商品报 pgvector 语法错误** | PostgreSQL 向量扩展未激活 | 登录数据库执行 `CREATE EXTENSION IF NOT EXISTS vector;`。 |
